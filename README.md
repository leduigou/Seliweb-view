# Seliweb-view

Thème WordPress d'accompagnement pour l'extension [**Seliweb-WP**](https://github.com/leduigou/seliweb) (gestion d'un S.E.L. — Système d'Échange Local).

Seliweb-WP fonctionne avec n'importe quel thème ; Seliweb-view fournit l'habillage graphique d'origine (bandeau, navigation, pied de page en zones de widgets, page FAQ en accordéon).

## Prérequis

- WordPress 6.0 ou supérieur
- PHP 7.4 ou supérieur
- L'extension [Seliweb-WP](https://github.com/leduigou/seliweb) installée et activée

## Installation

1. Téléchargez le zip de la [dernière release](https://github.com/leduigou/Seliweb-view/releases/latest) (`seliweb-view-X.Y.Z.zip`).
2. Dans l'administration WordPress : **Apparence → Thèmes → Ajouter un thème → Téléverser un thème**, sélectionnez le zip téléchargé, puis **Installer**.
3. Activez le thème.
4. Personnalisez-le dans **Apparence → Personnaliser** (identité du site, couleurs, image d'entête, pied de page) — voir le manuel utilisateur de Seliweb-WP pour le détail.

## Mises à jour

Les nouvelles versions sont publiées sur ce dépôt GitHub et détectées automatiquement par WordPress (Apparence → Thèmes), comme pour un thème classique du répertoire officiel.
